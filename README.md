# 📝 Scratch Notes

Scratch Notes is an interactive, infinite canvas note-taking application with a Scratch-style visual programming concept.

### ✨ Key Features
- Interactive Canvas: Zoom and Pan support (wide canvas navigation).
- Nodes & Connecting Lines: Connect notes using Cubic Bézier lines.
- Block Color Categories:
- 🟡 Important Note
- ⚪ Note
- 🔵 Task List Note
- 🟢 Formula Note
- 🟣 Reminder Note
